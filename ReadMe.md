## 📖 Sobre o Projeto

O **SoftTech** é uma **Landing Page** responsiva desenvolvida para apresentar e divulgar um curso de **Git e GitHub**, oferecendo uma experiência moderna e intuitiva para os visitantes.

O projeto foi idealizado com foco em boas práticas de desenvolvimento Front-End, priorizando uma interface limpa, navegação fluida e adaptação a diferentes tamanhos de tela. Desde a prototipação da interface no **Figma** até sua implementação com tecnologias web, o objetivo foi criar uma página atrativa capaz de apresentar informações sobre o curso de forma clara e objetiva.

---

## ✨ Funcionalidades

- 📱 Interface totalmente responsiva para diferentes dispositivos;
- 🎨 Layout moderno e intuitivo;
- 📚 Apresentação das informações do curso de Git e GitHub;
- ⚡ Navegação fluida e experiência otimizada para o usuário;
- 🖱️ Elementos interativos desenvolvidos com JavaScript;
- 🎯 Estrutura organizada para facilitar futuras manutenções.
